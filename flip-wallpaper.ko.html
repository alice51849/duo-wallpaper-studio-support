플립 배경화면: 작은 커버 화면과 큰 메인 화면을 한 쌍으로

플립폰은 접으면 작은 커버 화면, 펼치면 세로로 긴 큰 메인 화면을 씁니다. 두 화면의 크기와 모양이 이렇게 다르다 보니 사진 한 장을 양쪽에 넣으면 커버 화면에서는 주인공이 잘리거나 너무 작아 보이기 쉽습니다. 이 페이지에서는 두 화면에 맞는 한 쌍의 플립 배경화면을 고르는 기준, 설정하는 순서, 이미지 크기를 정리했습니다.

작은 커버 화면에 맞는 배경화면 고르는 기준

  1. 주인공은 하나만: 커버 화면은 작아서 여러 요소가 들어가면 무엇을 보여 주려는지 흐려집니다. 꽃 한 송이, 창가의 불빛처럼 한 부분을 크게 담은 클로즈업이 잘 어울립니다.
  2. 시계 자리를 비워 두기: 커버 화면은 잠금 화면 시계와 알림이 함께 보이는 경우가 많습니다. 주인공이 시계와 겹치지 않는지 미리 확인하세요.
  3. 또렷한 색 대비: 작은 화면에서는 세밀한 무늬보다 색이 분명한 장면이 한눈에 잘 들어옵니다.

큰 메인 화면과 한 쌍으로 맞추는 기준

  1. 같은 작품, 다른 거리: 커버 화면에는 장면의 한 부분을, 메인 화면에는 같은 장면의 전체 풍경을 넣으면 접었다 펼칠 때 이야기가 이어집니다.
  2. 아이콘이 놓일 여백: 메인 화면은 홈 화면 아이콘이 많이 올라가므로, 요소가 너무 빽빽하지 않은 전체 장면이 보기 편합니다.
  3. 색감 통일: 두 화면의 색 톤이 같으면 접었을 때와 펼쳤을 때가 하나의 세트로 느껴집니다.

폴더블 배경화면 - 커버·메인 세트 앱으로 만들기

폴더블 배경화면 - 커버·메인 세트는 폴더블폰과 플립폰의 두 화면을 위해 한 쌍으로 만든 배경화면 앱입니다. 접으면 커버 화면에 클로즈업, 펼치면 메인 화면에 전체 풍경이 보이며, 두 장 모두 같은 오리지널 작품에서 잘라냈습니다.

  • 300세트 이상, 배경화면 600장 이상, 14가지 스타일 (일러스트 풍경, 비 오는 밤의 창, 꽃, 노을과 구름빛, 마카롱 컬러, 도시 스카이라인 불빛 등)
  • 저장 전에 접은 상태와 펼친 상태를 미리 보고, 잠금 화면 시계가 어떻게 보이는지도 확인
  • 색상과 한 줄 문구, 5가지 글꼴, 크기, 불투명도, 위치로 나만의 세트 꾸미기
  • 만들기: 내 사진을 한 쌍으로 만들고 드래그해서 초점 위치 지정
  • 즐겨찾기와 최근 본 세트
  • 광고 없음, 계정 없음, 추적 없음

플립폰에 설정하는 순서

  1. 앱에서 마음에 드는 세트를 고르고, 미리보기로 접은 상태와 펼친 상태를 확인합니다.
  2. 세트의 두 이미지(커버 이미지, 메인 이미지)를 갤러리에 저장합니다.
  3. '배경화면으로 설정'을 누른 뒤 홈 화면, 잠금 화면 또는 둘 다를 고릅니다.
  4. 커버 이미지는 커버 화면에, 메인 이미지는 메인 화면에 설정합니다.

앱은 배경화면을 스스로 바꿀 수 없어서, 어떤 이미지를 어느 화면에 쓸지는 항상 직접 고릅니다.

이미지 크기는 어떻게 되나요

한 장을 두 화면에 늘려 쓰는 대신, 세트마다 커버 화면용과 메인 화면용 이미지 두 장을 따로 저장합니다. 각 이미지를 맞는 화면에 지정하면 한쪽은 잘리고 다른 쪽은 늘어나는 문제를 줄일 수 있습니다. 화면 크기는 기종마다 다르므로, 저장하기 전에 미리보기로 잘리는 부분이 없는지 확인하는 것이 가장 확실합니다. App Store 버전은 iPhone과 iPad에서 커버 화면 1398 x 2034, 메인 화면 2853 x 2007 크기로 저장합니다.

자주 묻는 질문

플립폰 커버 화면과 메인 화면에 같은 사진을 넣어도 되나요?
넣을 수는 있지만 작은 커버 화면에서는 사진의 일부만 보여서 주인공이 잘리거나 너무 작아 보이기 쉽습니다. 같은 작품에서 커버 화면용 클로즈업과 메인 화면용 전체 장면을 따로 잘라 쓰면 접고 펼칠 때 자연스럽게 이어집니다.

앱이 배경화면을 직접 바꿔 주나요?
아니요. 앱은 배경화면을 스스로 바꿀 수 없습니다. 세트의 두 이미지를 갤러리에 저장한 뒤 '배경화면으로 설정'에서 커버 이미지는 커버 화면에, 메인 이미지는 메인 화면에 직접 지정합니다.

내 사진으로도 플립 배경화면 한 쌍을 만들 수 있나요?
네. 만들기에서 사진을 고르고 드래그해서 초점 위치를 정하면 커버·메인 한 쌍이 만들어집니다. 구매하지 않고 저장한 이미지에는 작은 워터마크가 들어갑니다.

구매하지 않아도 쓸 수 있나요?
네. 구매하지 않아도 바로 저장할 수 있는 5세트가 있고, 내 사진을 한 쌍으로 만들 수도 있습니다. Studio Pro는 구독이 아닌 1회 인앱 구매로, 모든 세트를 열고 워터마크를 없애 줍니다.
